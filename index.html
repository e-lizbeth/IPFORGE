📚 Understanding Subnetting

🌐

What is an IPv4 Address?

An IPv4 address is a 32-bit number that uniquely identifies a device on a network. It is written as four decimal numbers (octets) separated by dots, for example 192.168.1.10. Each octet ranges from 0 to 255.

🎭

What Does a Subnet Mask Do?

A subnet mask is also a 32-bit number (e.g. 255.255.255.0). It separates the network portion of an IP address from the host portion. Bits set to 1 belong to the network; bits set to 0 identify individual hosts within that network.

📐

What is CIDR Notation?

CIDR (Classless Inter-Domain Routing) notation writes the prefix length after a slash, e.g. 192.168.1.0/24. The number after the slash tells you how many bits of the 32-bit address are the network part. A /24 means the first 24 bits are fixed, leaving 8 bits (256 addresses) for hosts.

🔗

Why is Subnetting Useful?

Subnetting divides a large network into smaller, isolated segments. This reduces congestion, improves security by separating departments, makes IP allocation more efficient, and simplifies network management and troubleshooting.
